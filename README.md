## 🌸 About The Portfolio

Welcome to the source code repository of my personal developer portfolio! 

Designed with a **sleek, modern aesthetic** featuring soft pink ambient glows, glassmorphism cards, and fluid interactions, this portfolio showcases my engineering projects, technical skill set, academic background, and algorithmic problem-solving journey.

### 🌟 Key Highlights

- 🎨 **Aesthetic Visual Design**: Tailored pastel gradients, glassmorphic frosted-glass cards, and ambient glowing orbs.
- ⚡ **Pure Vanilla Performance**: Zero heavy JavaScript frameworks or bundler bloat — built purely with clean, semantic **HTML5**, modern **CSS3**, and modular **ES6+ JavaScript**.
- 📱 **Flawlessly Responsive**: Optimized across all viewports (ultrawide monitors, laptops, tablets, and smartphones) using dynamic CSS Flexbox & CSS Grid.
- 📋 **1-Click Clipboard Utilities**: Instant copy-to-clipboard for email address with an interactive animated toast notification.
- 💌 **Integrated Quick-Contact Form**: Client-side validated form that immediately triggers pre-filled email dispatches.
- 📊 **Dynamic Scroll Progress Bar**: Smooth real-time reading progress indicator pinned to the top of the viewport.
- ♿ **Accessibility & SEO Ready**: Semantic landmarks, descriptive alt text, accessible ARIA labels, and clean meta tags.

## 🛠️ Local Setup & Preview

To run this portfolio locally on your machine, follow these simple steps:

### 1. Clone the repository
```bash
git clone https://github.com/nikksingh9/portfolio.git
cd portfolio
```

### 2. Launch the application
Since this is a lightweight static site built with standard web technologies, no build step or package installations are required!

- **Option A: Direct Browser Launch**  
  Double click `index.html` or open it in your preferred browser:
  ```bash
  # Windows
  start index.html

  # macOS
  open index.html

  # Linux
  xdg-open index.html
  ```

- **Option B: Using VS Code Live Server**  
  Open the project in VS Code, right-click `index.html`, and choose **"Open with Live Server"**.

- **Option C: Using Python HTTP Server**  
  ```bash
  python -m http.server 3000
  # Then navigate to http://localhost:3000 in your browser
  ```
